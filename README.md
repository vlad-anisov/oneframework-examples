# oneframework-examples

Приложения-примеры для [One Framework](https://github.com/vlad-anisov/oneframework).

Здесь они лежат все вместе, а не при своих привязках, и это не про опрятность.
Пример — единственное место, где видно **всё сразу**: объявление, сборку и
поведение на устройстве. Разложенные по трём репозиториям, они читались бы как
приложения к библиотекам; собранные вместе — как то, чем каркас пользуются.

## Что здесь есть

| Пример | Язык | Про что он |
|---|---|---|
| `todo` | Python | Список дел: поиск, отборы, порядки, перетаскивание |
| `todo-js` | JavaScript | Тот же список, объявленный второй привязкой — документы совпадают побайтово |
| `gtasks` | Python | Собран **из модулей**; вкладки по данным, меню, складные блоки, логика на устройстве |
| `kitchen` | Python | Все типы полей и все виджеты разом |
| `gallery` | Python | Показ картинок |
| `showcase` | Python | Витрина узлов вида |
| `bigdata` | Python | Список в двести тысяч строк: окно и подкачка |
| `modular` | Python | Наименьшее модульное приложение |
| `notes-python` | Python | Заметки; логику считает Pyodide |
| `notes-js` | JavaScript | Те же заметки; логику считает движок вебвью |
| `notes-kotlin` | Kotlin | Те же заметки; логика — скомпилированный модуль WebAssembly |

Тройка `notes-*` — не три примера, а один, написанный трижды. Различается
ровно то, чем на устройстве считается логика; объявления всех трёх дают
побайтово одинаковые документы, и это проверяется прогоном.

## Как запустить

```bash
oneframework build web todo/app.py       # приложение на Python
npx oneframework build web todo-js/app.mjs   # на JavaScript
oneframework build web notes-kotlin/App.kt   # на Kotlin
```

Нужны привязка того языка, на котором написан пример, и
[ядро](https://github.com/vlad-anisov/oneframework).
